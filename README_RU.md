# SecretChat

> **English documentation:** [README.md](README.md)

<p align="center">
  <img src="screenshots/chat/logo.jpg" alt="SecretChat">
</p>

Небольшой приватный P2P-мессенджер с шифрованием. Никаких аккаунтов, серверов
и регистраций — вы соединяетесь **напрямую** по IP собеседника с разовым
кодом, и у каждого чата свой новый ключ шифрования.

- **Прямой P2P** — без сервера посередине, всё идёт напрямую между двумя
  компьютерами по TCP.
- **Шифрование сквозное** — X25519 (ECDH) при рукопожатии + AES-256-GCM для
  каждого сообщения. Каждый чат выводит свой ключ: новый чат = новое шифрование.
- **Эфемерность по замыслу** — ничего не пишется на диск. Закрыл программу —
  все чаты стёрты **у обоих**. Создатель чата может поставить таймер
  самоуничтожения (5 мин … 24 ч) — по истечении чат стирается сам везде.
- **14 тем**, интерфейс RU/EN, звук уведомлений, текст + файлы + фото
  (вставляй скриншот через Ctrl+V).
- Работает как обычное Python-приложение, как нативный **.exe / .app** и в
  **Docker** (GUI через noVNC в браузере — можно держать на любом сервере).

## Быстрый старт (исходники)

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt     # Windows: .venv\Scripts\pip ...
.venv/bin/python main.py                       # Windows: .venv\Scripts\python ...
```

Два человека запускают это, затем:

1. **Создатель** жмёт **Новый чат**, при желании выбирает таймер
   самоуничтожения и получает буквенно-цифровой **код** (выглядит как
   `AE56-OQBY-…-7PAU`). Передай его собеседнику вместе со своим IP.
2. **Собеседник** жмёт **Подключиться**, вводит твой **IP** и **код** — готово.

Код — это, по сути, «сейфти-номер»: в него зашит твой публичный ключ, поэтому
подмениться под одну из сторон невозможно. Свой адрес смотри в **Мой IP**.

## Docker

Контейнер сам поднимает виртуальный дисплей (Xvfb), VNC-сервер и noVNC — то
есть GUI **открывается автоматически**, а управлять им можно из любого
браузера:

```bash
make up                       # собрать и запустить (или docker compose up -d --build)
# открыть: http://localhost:6080/vnc.html    (пароль VNC: secret)
```

- **noVNC** `6080` — интерфейс приложения во вкладке браузера.
- **VNC** `5900` — для любого VNC-клиента (тот же пароль).
- **P2P** `42000` — сюда подключаются к тебе; открой его на роутере/фаерволе
  VPS, чтобы к тебе могли достучаться из интернета.
- `config.py` примонтирован volume'ом — правь без пересборки.

Все настройки (порты, пароль VNC, разрешение экрана, тему, лимиты…) лежат в
`config.py` в корне проекта — правишь и перезапускаешь. Пароль VNC по
умолчанию `secret` (см. `VNC_PASSWORD`).

## Сборка нативных приложений

Все скрипты сборки создают собственный build-venv (`.venv-build`) — твоё
основное окружение остаётся чистым. PyInstaller-сборки используют общую
спецификацию `secretchat.spec` (UPX выключен — он триггерит антивирусы).

### Windows

**Nuitka (рекомендуется)** — компилирует Python в нативный код, и антивирусы
помечают такой exe заметно реже, чем PyInstaller (без UPX и без распаковки в
temp):

```
build\build_windows_nuitka.bat            # результат: dist\SecretChat\SecretChat.exe
build\build_windows_nuitka.bat onefile    # или один файл: dist\SecretChat.exe
build\build_windows_nuitka.bat mingw      # собрать через MinGW вместо MSVC
```

Нужен Python в PATH и компилятор C — MSVC (Visual Studio Build Tools) или
MinGW-w64 (подробности в начале скрипта).

**PyInstaller (запасной)**:

```
build\build_windows.bat                   # результат: dist\SecretChat.exe
```

### macOS

```
chmod +x build/build_macos.sh
./build/build_macos.sh                    # результат: dist/SecretChat.app
```

Если раздаёшь приложение — сперва подпиши его (см. комментарии в скрипте).

### Linux

```
chmod +x build/build_linux.sh
./build/build_linux.sh                    # результат: dist/SecretChat
```

Нужны `python3`, `python3-venv` и системные библиотеки Qt
(`sudo apt install build-essential libgl1 libegl1 libxkbcommon0` на
Debian/Ubuntu). Либо просто запускай из исходников — см. *Быстрый старт*.

### Docker (ничего не компилируем на своей машине)

Сборка в контейнере описана отдельно — см. раздел **Docker** выше (`make up`,
GUI в браузере через noVNC).

> **Про «предупреждения» Windows.** Любой неподписанный exe (не только этот)
> SmartScreen встречает синим экраном — это норма и это **не вирус**.
> Бесплатно убрать это предупреждение нельзя (нужен платный сертификат
> Microsoft), поэтому мы выбрали Nuitka — чтобы антивирусы *ложно* не
> срабатывали, и собрали памятку, что нажать пользователю:
> **`docs/SMARTSCREEN_FAQ_RU.md`** (и `docs/SMARTSCREEN_FAQ.md`).

## Настройка

Всё настраивается «с порога» в **`config.py`**:

| Секция       | Что там                                                                  |
|--------------|--------------------------------------------------------------------------|
| `[APP]`      | имя, версия, язык/тема по умолчанию, звук, автостарт сервера            |
| `[NETWORK]`  | P2P-порт, интервалы keepalive/таймауты, таймаут подключения              |
| `[SECURITY]` | макс. размер файла, размер чанка, таймер по умолчанию, проверка кода     |
| `[UI]`       | размер шрифта, ширина пузырей/картинок, размер окна, список из 14 тем    |
| `[LOG]`      | журнал вкл/выкл, уровень, файл                                           |
| `[DOCKER]`   | разрешение виртуального дисплея, пароль и порты VNC                      |

Цвета 14 тем лежат отдельно в **`secret_chat/themes.py`** (`PALETTES`) — каждая
тема это словарь из 14 цветов (`bg`, `panel`, `header`, `input`, `me`, `them`,
`text`, `dim`, `accent`, `border`, `hover`, `danger` + `me_fg`/`accent_fg` для
текста на цветных поверхностях); скопируй тему, поменяй цвета и добавь её id в
`THEMES` в `config.py`.

## Как устроено шифрование

1. **Создатель** генерирует пару X25519. Публичный ключ пакуется в код
   подключения вместе с контрольной суммой (base32, группы через дефис).
2. **Собеседник** генерирует свою пару и при рукопожатии шлёт публичную часть.
3. Обе стороны по ECDH получают один и тот же общий секрет и выводят ключ
   AES-256 через HKDF (соль — от кода).
4. После рукопожатия **всё** шифруется AES-GCM со свежим nonce на каждый кадр:
   текст, куски файлов и даже пинги.
5. Код подключения служит и аутентификацией — MITM потребовалась бы пара
   ключей, совпадающая с кодом, что вычислительно невозможно.

Чат живёт только в памяти. Закрыл приложение — сокет умирает, вторая сторона
видит обрыв связи и стирает чат. С таймером самоуничтожения обе стороны
отсчитывают время и стирают всё одновременно на нуле.

## Приватность

- Без аккаунтов, регистраций, телеметрии и внешних запросов при старте.
- На диск ничего не сохраняется: история, ключи и принятые файлы только в
  памяти (недокачанные передачи — во временном файле, который удаляется при
  отмене/ошибке).
- Кнопка **Внешний IP** в *Мой IP* шлёт стандартный STUN-запрос на
  `stun.l.google.com` (обычный шаг P2P) — это опционально.
- Keepalive-трафик нужен, чтобы ловить мёртвые соединения и корректно
  стирать чаты.

## Сетевые нюансы

В **локальной сети** работает всегда. Через интернет той стороне, к которой
подключаются, нужен проброс порта (`42000`) или UPnP — если обе стороны за NAT
без этого, TCP не установится (это свойство интернета, а не приложения).

```

main.py                 # точка входа
secret_chat/
  crypto.py             # X25519, AES-GCM, HKDF, коды подключения
  protocol.py           # формат кадров поверх TCP
  network.py            # TCP-сервер/клиент, keepalive
  manager.py            # состояние чатов, рукопожатие, самоуничтожение
  i18n.py               # строки RU/EN
  themes.py             # 14 цветовых тем + сборка QSS
  sound.py              # синтезированный «бип»
  prefs.py              # runtime-настройки поверх config.py
  ui/                   # интерфейс на PySide6
docker/entrypoint.py    # Xvfb + x11vnc + noVNC + автозапуск GUI
tests/                  # headless-тесты ядра и UI
build/                  # сборка: Nuitka (Windows), PyInstaller (Win/macOS/Linux), dmg
dist/                   # готовые бинарники: .app / .dmg / .exe
docs/                   # памятка про SmartScreen/антивирусы (RU/EN)
```
