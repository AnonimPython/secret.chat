# Windows ругается на SecretChat.exe? Разбираемся

Это короткая памятка для тех, кому ты дашь приложение. Прочитай — и никакой
паники.

## Почему Windows показывает предупреждение?

Потому что **у приложения нет платной подписи кода**. Microsoft требует
сертификат (он стоит денег, ~$100–300/год), чтобы Windows заранее «доверял»
разработчику и не показывал синий экран SmartScreen.

Важно: **предупреждение ≠ вирус**. Это просто «мы не знаем этого издателя».
Точно так же Windows встречает тысячи легальных бесплатных программ.

## Что за приложение?

- Открытый исходный код — можешь сам прочитать каждую строчку.
- Ничего не собирает: без аккаунтов, без телеметрии, без серверов.
- Соединяется **напрямую** с IP, который ты сам вводишь.
- Все сообщения шифруются, чаты стираются при закрытии.

## Как открыть

**Вариант 1 — синий экран SmartScreen «Windows защитил ваш компьютер»:**

1. Нажми **Подробнее** (More info).
2. Нажми **Выполнить в любом случае** (Run anyway).
3. Готово.

**Вариант 2 — приложение не запускается, но и экрана нет:**

1. Правый клик по `SecretChat.exe` → **Свойства** (Properties).
2. Внизу, если есть галочка **Разблокировать** (Unblock) — поставь её.
3. **OK** и запускай.

Это одноразовое действие, дальше приложение открывается просто так.

## Антивирус всё равно ругается (ложное срабатывание)

Бывает: файл загружен из интернета и какой-нибудь антивирус заподозрил его.
Что делать:

1. **Не удаляй сразу.** Сверь: файл называется `SecretChat.exe`, лежит там,
   откуда его положили, скачан от того, кого ты знаешь.
2. Сообщи о ложном срабатывании в Microsoft — это бесплатно и реально
   помогает:
   https://www.microsoft.com/en-us/wdsi/filesubmission
   (выбираешь файл, ставишь «не вредоносный» / false positive).
3. Чем больше людей так нажмёт «Выполнить в любом случае» и сообщит — тем
   быстрее файл получит «репутацию» и перестанет ругаться везде.

## Как правильно передавать файл

- **Плохо:** скинуть exe напрямую в мессенджер/почту/браузер — Windows ставит
  метку «скачано из интернета» и ругается сильнее.
- **Хорошо:** положить в **zip-архив**, на флешку или в **GitHub Releases** —
  так предупреждений меньше, а на GitHub репутация копится автоматически.
- **Лучше всего:** папка `dist\SecretChat\` (standalone-сборка) вместо одного
  файла — антивирусы её помечают реже всего.

## Почему нельзя убрать предупреждение совсем?

Полное «тихое» открытие даёт только официальный сертификат подписи кода от
Microsoft (платный). Бесплатных «обходов» не существует — любые обманные
приёмы (поддельная подпись, «левые» сертификаты) только добавят проблем:
антивирусы заклеймят файл как вредоносный. Поэтому честный путь — открыть
один раз через «Подробнее → Выполнить в любом случае».
